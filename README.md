# The World in Numbers

[![make.fun bounty](https://make.fun/badge/best-national-statistics-site-20261126-0539.svg)](https://make.fun/bounty/best-national-statistics-site-20261126-0539)
[![make.fun rank](https://make.fun/badge/best-national-statistics-site-20261126-0539/claymoreth/world-in-numbers-entry/rank.svg)](https://make.fun/bounty/best-national-statistics-site-20261126-0539)
[![make.fun reward](https://make.fun/badge/best-national-statistics-site-20261126-0539/claymoreth/world-in-numbers-entry/reward.svg)](https://make.fun/bounty/best-national-statistics-site-20261126-0539)

A reference atlas of the world's ten largest economies — GDP, population,
human development and demographics, 2020–2025. All figures come from four
official publications (IMF World Economic Outlook October 2026, World Bank
World Development Indicators July 2026, UNDP Human Development Report 2025,
UN World Population Prospects 2024); regional totals are calculated from the
country figures and labelled as calculated.

Six pages, fully static, no network requests: Overview (KPI cards + GDP line
chart with switchable series), Rankings (sortable table), Regions
(simplified world map with four switchable layers + country detail and
comparison), Demographics (age-sex population pyramid, 1950 and 2025),
Data Tables (all 124 figures, live search) and Sources.

Serve locally with `node serve.ts`, then open http://localhost:8080.
Hand in with `node main.ts` (writes `/output`, or `MAKEFUN_OUTPUT_DIR`).
